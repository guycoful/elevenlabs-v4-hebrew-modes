# הקראה בעברית עם מצבי דיבור, ElevenLabs v4

סקיל לקלוד קוד שמלמד אותו להקריא עברית ב-ElevenLabs v4 עם 25 מצבי דיבור: לחישה, בכי, שדר ספורט, שירה, גמגום, דמות מצוירת ועוד, ועם 9 אירועי קול.

## התקנה
1. להעתיק את התיקייה `elevenlabs-v4-hebrew-modes` אל `~/.claude/skills/` (בווינדוס: `%USERPROFILE%\.claude\skills\`).
2. ליצור מפתח API בחשבון ElevenLabs ולהגדיר אותו כמשתנה סביבה בשם `ELEVENLABS_API_KEY`. לא לשים אותו בקובץ בריפו ולא להדביק בצ'אט.
3. לפתוח את קלוד קוד ולבקש: "הקרא בעברית בלחישה: זה סוד".

יש ב-ElevenLabs תוכנית חינמית עם מכסה מוגבלת. את המכסה והמחיר הנוכחיים בדקו בעמוד התמחור שלהם.

## להתחיל עם הקול שלכם
מקליטים כמה דקות דיבור רגיל, בחדר שקט וללא מוזיקה, ואז:
```
python3 scripts/clone_my_voice.py --name "הקול שלי" --sample my_voice.mp3 --i-confirm-this-is-my-own-voice
```
הסקריפט מדפיס `voice_id`, ובו משתמשים בהקראה. הדגל הוא הצהרה שההקלטה שלכם, או שיש לכם אישור כתוב מבעל הקול. יצירת קול תופסת מקום בחשבון (voice slot). הסקריפט נבדק מול שרת מדומה בלבד ולא מול ElevenLabs עצמו, ולכן אם יש שגיאה, תדווחו.

## בדיקה בלי קרדיטים
```
python3 scripts/speak.py --list-modes
python3 scripts/speak.py --mode whisper --text "זה סוד" --dry-run
```

## חשוב
- כל הקראה אמיתית עולה קרדיטים בחשבון שלכם.
- שכפול קול של אדם אחר דורש אישור שלו בכתב. הסקיל לא משכפל קולות.
- מה נבדק: בתמלול חוזר של כעשרה קליפים, התגיות לא הוקראו כטקסט. מה לא נבדק: איכות ההגשה בעברית באוזן, ואירועי הקול (עיטוש, דפיקות, קהל). תשמעו לפני שמשתמשים בפרודקשן.
